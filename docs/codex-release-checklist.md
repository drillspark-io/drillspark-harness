## 告知の計測

- Codex導入リンク: utm_campaign=drillspark_harness、utm_content=codex_setup。
- GitHub/記事/Xなど媒体ごとにutm_sourceを分ける。URLをコピーしただけで初回利用を計測したことにしない。
- GA4: 導入ページ訪問と登録。MCP利用は既存のサーバー側利用ログで別集計。
- Codex経由のMCP利用を区別する情報がログに無ければ、全MCPの増加をCodex効果と断定しない。
  登録時のキャンペーンと接続後の利用を結べる範囲を確認してから転換率を出す。
- 生のAPIキーをログの識別子に使わない。計測実装の追加はDrillSpark本体で別変更として扱う。

実機確認が終わってから対応下限バージョンと確認済みOSをREADMEへ反映する。
