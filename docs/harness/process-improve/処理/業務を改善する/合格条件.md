## 3. 合格条件とそのテストデータ

**実装より先に書く。** あとから書くと実装に合わせて条件のほうが緩む。
決定論で判定できるものだけを書く。**終了コードだけを見る条件にしない** —
違反サンプル1件につき、**意図した指摘が1件だけ出ること**まで確かめる
（全部 exit 2 を返す壊れた lint も「違反サンプルで2」を満たすため）。

```bash
bash tests/run.sh          # 既存16件 ＋ 下の追加分。既存に触れない
```

| # | 条件 | 判定方法 | 期待 |
