## 図が宣言した人間の介入点

**5種すべてを数える。1つも無いなら「無し」と明記する。**

| 種別 | 図・ノードID | 備考に書いた内容 |
|---|---|---|
| 起動 | root `1` | 利用者が skill を呼ぶ。**自動起動しない** |
| 承認ゲート | `2_9`（業務一覧）／ `4_5`（工程）／ `4_8`（作業） | **3つ。** 止まって確認を取る |
| 実行 | `2_6`（仕事の内容と目的を答える）／ `3_4`（業務を選ぶ）／<br>`4_4` `4_7`（直したい所を言う）／ `5_3`（成功の形に合意）／<br>`5_5` `5_6`（案を選ぶ）／ `6_3`（任せ方に合意）／ `6_5`（承認の有無を決める） | 人間がやる作業。**エージェントに代行させない** |
| エスカレーション先 | 全図のループ上限の備考 | **詰まった時点で利用者が指名する相手。**開始時には決めさせない |
| 基準の決定 | 全図の Start の備考 | 「基準の決定＝判定基準ファイル」。**利用者も AI も決めない** |
