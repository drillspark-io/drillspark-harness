**そのままでは使えない。**

| 検査コード | 処理2で | 理由 |

| `EXTERNAL_REF` | **効く** | 処理2も外部通信なし・依存ライブラリなし |

→ 「拡張か新規か」の前に、**そのままでは通らない**。

## 3. 合格条件とそのテストデータ

**実装より先に書く。** 決定論で判定できるものだけを書く。
違反サンプル1件につき、**意図した指摘が1件だけ出ること**まで確かめる。

```bash
bash tests/run.sh          # 既存16件 ＋ 下の追加分。既存に触れない
```

| # | 条件 | 判定方法 | 期待 |
|---|---|---|---|
| 7 | 1枚の検査が**8つの塊の欠け**を見つける | `node scripts/process-plan-lint.js tests/ng-plan-missing-block.html` | exit 2 ／ `MISSING_BLOCK` x1 |
| 8 | 1枚の検査が**外部参照**を見つける | 同 `tests/ng-plan-external.html` | exit 2 ／ `EXTERNAL_REF` x1 |
| 9 | 1枚の検査が**印の欠落**を見つける | 同 `tests/ng-plan-no-mark.html` | exit 2 ／ `MISSING_MARK` x1 |
| 10 | 1枚の検査が**DrillSparkのURLを通す** | 同 `tests/ok-plan-minimal.html` | **exit 0**（既存 view-lint はここで落ちる） |
| 11 | 保存の検査が**実在しないファイル**を見つける | `node scripts/file-saved-lint.js <無いパス>` | exit 2 ／ `NOT_SAVED` x1 |
| 12 | 保存の検査が**実在するファイルを通す** | 同 `tests/ok-plan-minimal.html` | **exit 0** |
| 15 | 1枚の検査が**絶対パスとメール**を見つける | 同 `tests/ng-plan-private.html` | exit 2 ／ `PRIVATE_INFO` x1 |

**#10 が既存 view-lint との違いを固定する条件。** DrillSpark の URL（UUID を含む）を
私的情報として弾かないことを、テストで縛る。**1枚から図へ戻る導線を消すと目的に反する。**

**2026-09-02 追記**: 保存先の名前を `業務改善/改善計画-<業務名>.html` に固定（規約が無く、lint の例の
