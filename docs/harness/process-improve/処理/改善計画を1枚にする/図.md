## 図が宣言した人間の介入点

**5種すべてを数える。1つも無いなら「無し」と明記する。**

| 種別 | 図・ノードID | 備考に書いた内容 |
|---|---|---|
| 起動 | root `1` | 利用者が skill を呼ぶ。**自動起動しない。処理1の連鎖に入らない** |
| 承認ゲート | — | **0個。** この処理は判定も承認も持たない（描くだけ） |
| 実行 | `2_5`（どの業務かを選ぶ） | `lane: human` と明記。**エージェントに代行させない** |
| エスカレーション先 | ループ上限の備考 | **詰まった時点で利用者が指名する相手。**開始時には決めさせない |
| 基準の決定 | Start の備考 | **無し。** この処理は判定しない。合否を持つのは判定基準ファイルの側（`process-improve` のもの）— root 図の Start 備考のとおり（2026-09-02 訂正） |
